## Story

**En tant que** DJ,
**je veux** retrouver mes réglages au lancement et régler les durées du moteur et de la feutrine,
**afin de** garder ma configuration sans lecture automatique.

## Critères d'acceptation

1. **Magasin `UserDefaults` (SF-17, SF-24, D-17).** `UserDefaultsPreferencesStore`, injectable et testé sous Linux, conserve dans un document JSON unique (clé `app.scratchapp.preferences.v1`) : par platine, RPM, pitch et résistance ; globalement, position du crossfader, courbe, hamster, faders de voie, durées de démarrage et de freinage, temps de rattrapage (communs aux deux platines).
2. **Premier lancement (3.1, 3.2, SF-68 ; 6.7 « Afficher le réglage sur l'interface principale »).** 33⅓ RPM, pitch 0 %, résistance 50 %, crossfader au centre, coupure franche, hamster désactivé, faders à 100 %, 0,7 s, 1,0 s et 60 ms.
3. **Valeurs invalides (SF-11, SF-21, SF-68).** Une valeur hors bornes est ramenée à sa borne ; une valeur illisible ou une clé absente prend la valeur par défaut ; un document illisible donne les valeurs par défaut, sans erreur.
4. **Restauration sans lecture (SF-17, RM-10, PO-12, D-45 ; 6.5 « Restaurer les préférences », 6.7 « Restaurer le réglage mémorisé », 6.10 « Conserver les réglages de crossfader »).** Au lancement, l'`AppModel` applique `preferences.load().engineCommands` au moteur : aucune commande `motor` ni `load`, aucun rechargement de son.
5. **Écritures regroupées.** Chaque changement de réglage est enregistré par écritures regroupées (0,5 s après le dernier changement), jamais depuis le fil audio ; `AppModel` expose un enregistrement immédiat appelé au passage en arrière-plan (6.2).
6. **Écran Réglages (3.3, D-18 ; 6.2 « Régler les durées de démarrage et de freinage », 6.9 « Rattrapage réglable », « Rattrapage plus lent »).** iOS : feuille « Réglages » ; Mac : fenêtre Réglages standard (⌘,). Sections Moteur (durée de démarrage et de freinage, 0,1 à 5,0 s par pas de 0,1 s) et Feutrine (temps de rattrapage, 0 à 300 ms par pas de 10 ms), valeurs appliquées immédiatement ; sur Mac, section Clavier avec « Afficher les raccourcis clavier », qui ouvre l'aide fournie par 5.1.
7. **Accessibilité (SF-83).** Libellés et valeurs VoiceOver de l'UX (« Durée de démarrage », « 0,7 seconde » ; « Temps de rattrapage de la feutrine », « 60 millisecondes »), réglage au clavier et par les actions d'accessibilité, identifiants `settings.startDuration`, `settings.brakeDuration`, `settings.catchUp`, `settings.keyboardHelp`.

## Dev Notes

### Contrats et types existants (0.2)

```swift
public struct AppPreferences: Codable, Equatable, Sendable {     // livré et testé (ADR-11)
    public struct Deck: Codable, Equatable, Sendable { public var speed: TurntableSpeed; public var pitch: Double; public var resistance: Double }
    public struct Mixer: Codable, Equatable, Sendable {
        public var crossfader: Double, crossfaderCurve: Double, hamster: Bool, lineFaders: DeckPair<Double>
    }
    public var version: Int; public var decks: DeckPair<Deck>; public var mixer: Mixer; public var motor: MotorTimings
    public static let currentVersion: Int, defaults: AppPreferences
    public init(snapshot: EngineSnapshot)                          // ce qu'il faut enregistrer
    public func sanitized() -> AppPreferences
    public var engineCommands: [EngineCommand] { get }             // jamais motor ni load (RM-10)
}
public protocol PreferencesStoring: Sendable {
    func load() -> AppPreferences                                  // jamais d'erreur
    func save(_ preferences: AppPreferences)
}
public final class UserDefaultsPreferencesStore: PreferencesStoring {   // squelette : défauts, n'enregistre rien
    public static let defaultKey: String                           // "app.scratchapp.preferences.v1"
    public init(defaults: UserDefaults = .standard, key: String = defaultKey)
}
```

Commandes moteur concernées : `.startDuration(Double)`, `.brakeDuration(Double)`, `.slipmatCatchUp(Double)` (le moteur borne) ; l'écran lit `EngineSnapshot.motorTimings`.

### Pièges connus

- **Aucune lecture automatique** : `engineCommands` ne contient jamais `motor` ni `load` (test `testEngineCommandsNeverStartMotorsOrLoad_RM10`, existant) ; les sons chargés ne sont pas restaurés (PO-12 en P2, D-45).
- **UserDefaults sous Linux** : disponible dans swift-corelibs-foundation ; utiliser une suite unique par test et la supprimer (`removePersistentDomain(forName:)`).
- **Détection des changements** : comparer l'`AppPreferences(snapshot:)` courant au dernier enregistré à chaque `tick()` (structure légère) ; ne pas enregistrer à chaque image.
- **Champ numérique Mac** : virgule décimale française (« 0,7 ») ; utiliser un formateur à la locale `fr_FR` et ramener hors plage à la borne.
- **Aide des raccourcis** : fenêtre déclarée par 5.1 (`Window` ou identifiant de fenêtre) ; l'ouvrir par `openWindow(id:)` ; si 5.1 n'est pas encore fusionnée, cette story attend (dépendance).
- **Langue (D-42)** : identifiants en anglais, `///` en français, `//` en anglais.
