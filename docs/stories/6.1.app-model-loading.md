## Story

**En tant qu'**utilisateur,
**je veux** importer un son ou charger la démo sur la platine de mon choix,
**afin de** commencer à scratcher en quelques secondes.

## Critères d'acceptation

1. **Composition (architecture §2.3).** L'`AppModel` (`@Observable`) compose bibliothèque, décodeur, moteur, hôte et modèles de présentation par leurs protocoles et implémente `DeckIntents` (4.1). Il fonctionne avec le faux moteur et un décodeur factice (aperçus, tests) comme avec les composants réels ; `ScratchAppMain` compose les composants réels disponibles (`ScratchEngine`, `AudioEngineHost`, `LibraryStore(locations: .standard())`, `AudioFileDecoder`, `UserDefaultsPreferencesStore`) et affiche `RootView` avec ce modèle.
2. **Sélecteur du système (SF-02 ; 6.1 « Importer un fichier WAV », « Importer depuis le Finder sur Mac »).** « Importer » ouvre le sélecteur pour la platine d'origine : Fichiers sur iPhone et iPad, panneau d'ouverture macOS (titre « Importer sur la platine A », bouton « Importer ») filtré sur WAV, AIFF, MP3 et M4A, un seul fichier. L'accès au fichier choisi (security-scoped) n'est ouvert que pendant la copie.
3. **Après un import réussi (SF-02, SF-03, RM-57 ; 6.1).** Entrée ajoutée à la bibliothèque, décodage hors du fil principal avec indicateur (`DeckViewModel.activity`), son chargé sur la platine d'origine dans l'état SF-03, `loadedEntry` et `loadedClip` renseignés ; l'autre platine n'est pas modifiée ; un contenu déjà présent charge l'entrée existante avec le bandeau « Déjà dans la bibliothèque : « nom » a été chargé. » (SF-75, `@P1`).
4. **Annulation (6.1 « Annuler l'importation »).** Annuler le sélecteur ne change rien.
5. **Erreurs et réconciliation (RM-48, D-11 ; 6.1 ; 6.13 « Copie supprimée en dehors de l'application », « Charger un son dont la copie a disparu »).** Chaque erreur affiche l'alerte française de l'UX §8.3 (espace de stockage insuffisant, format non pris en charge, fichier protégé, fichier illisible, son trop long, son trop court, échec de l'import) ; le son déjà chargé et son état sont conservés. Au lancement, l'`AppModel` appelle `library.reconcile()` et signale les entrées retirées par un bandeau (UX §8.5) ; avant chaque chargement depuis la bibliothèque, une copie disparue (`notFound`) donne l'alerte « Son introuvable » et la liste est mise à jour ; un son déjà chargé continue d'être joué depuis la mémoire.
6. **Démo (SF-76 ; 6.1 « Charger le son de démonstration »).** « Charger la démo » charge le son de démonstration sur la platine, sans lecture ; le clip de démo est généré une fois (tâche détachée) et partagé entre A et B.
7. **Remplacement (critère P1 porté par cette story, D-19, D-40 ; SF-15 ; 6.5 « Charger un deuxième fichier sur une platine active », « … à l'arrêt », « Refuser le remplacement »).** Platine chargée et active (`DeckSnapshot.isActive`, évaluée à la fin de la copie) ⇒ confirmation « Remplacer le son de la platine A ? » ; platine chargée à l'arrêt ⇒ remplacement direct ; platine vide, même plateau en rotation ⇒ aucune confirmation, le chargement arrête le moteur ; refus ⇒ son et état conservés, nouveau son gardé en bibliothèque, bandeau « « nouveau » a été ajouté à la bibliothèque. » ; après remplacement, état SF-03.
8. **API pour les autres stories.** L'`AppModel` expose le chargement d'une entrée sur une platine (avec les règles du critère 7), le déchargement d'une platine, la liste des platines qui portent une entrée, la confirmation et l'erreur courantes, le bandeau courant (utilisés par 3.5 et 5.2).
9. **Tests macOS** avec `RecordingEngine` ou le faux moteur, un décodeur factice et une bibliothèque en dossier temporaire.
10. **Index illisible (NFR12, PRD 3.1 CA2, D-49).** Si, au lancement, la bibliothèque a mis de côté un index illisible (bibliothèque réinitialisée) ou partiellement illisible (entrées ignorées), l'`AppModel` affiche une seule fois le bandeau correspondant de l'UX §8.5. S'il survient au même lancement que des entrées retirées par `reconcile()`, seul ce bandeau est affiché. Sans changement de contrat : `LibraryStore` (type concret, ScratchLibrary) expose publiquement l'issue de la lecture de l'index (aucune, réinitialisée, partielle), et `ScratchAppMain` la transmet à l'`AppModel` ; les doubles de test la fournissent directement. Suppose le correctif #51 (mise de côté unique), livré avec la 3.2.

### Contrats et points d'accroche

```swift
// Contracts
public protocol LibraryStoring: Sendable {
    var entries: [LibraryEntry] { get async }
    func reconcile() async -> [LibraryEntry]                    // 3.1 (D-11) : entrées retirées
    func importFile(at url: URL) async throws -> ImportResult   // 3.2 : .added / .existing
    func delete(id: UUID) async throws
    func url(for id: UUID) async throws -> URL                  // copie vérifiée ; notFound sinon
}
public protocol AudioDecoding: Sendable { func decode(url: URL, title: String) async throws -> AudioClip }
public enum EngineCommand { case load(DeckID, AudioClip), unload(DeckID) /* … */ }
public struct DeckSnapshot { public var isLoaded: Bool { get }; public var isActive: Bool { get } }

// ScratchUI (4.1, Léa)
@MainActor public protocol DeckIntents: AnyObject {
    func importFile(on deck: DeckID); func loadDemo(on deck: DeckID)
    func importDroppedFile(_ url: URL, on deck: DeckID); func openLibrary(); func openSettings()
    func revealLibraryInFinder()
}
DeckViewModel.loadedEntry: LibraryEntry?, .loadedClip: AudioClip?, .activity: DeckActivity   // posés par l'AppModel

// ScratchLibrary (3.3)
DemoSound.makeClip() -> AudioClip; LibraryEntry.demo(title:duration:); LibraryEntry.demoID
```

### Flux de chargement (architecture §4.1)

1. Intention « importer sur A » → sélecteur → URL → `startAccessingSecurityScopedResource()` → `await library.importFile(at:)` → `stopAccessing…` (dans un `defer`).
2. `.existing(entry)` → bandeau de dédoublonnage ; `.added(entry)` → liste mise à jour.
3. Platine chargée et active ? → confirmation (évaluée maintenant, après la copie).
4. `await library.url(for: entry.id)` → `Task.detached { try await decoder.decode(url:, title: entry.title) }` → retour sur le `MainActor`.
5. `engine.send(.load(deck, clip))` ; `loadedEntry`, `loadedClip`, `activity = .idle`.
6. Le clip remplacé est libéré par `drainReleasedClips()` dans `tick()` (fil principal).

Sur toute erreur : alerte, aucune commande envoyée, platine inchangée (RM-48).

### Textes (UX §8.3 à §8.5 ; « cet iPhone », « cet iPad » ou « ce Mac » selon l'appareil)

| Cas | Titre | Message |
|---|---|---|
| `insufficientStorage` | Espace de stockage insuffisant | « nom » n'a pas pu être copié dans ScratchApp. Libérez de l'espace sur cet iPhone, puis réessayez. |
| `unsupportedFormat` | Format non pris en charge | « nom » n'est pas un fichier audio pris en charge. Formats acceptés : WAV, AIFF, MP3 et M4A (AAC ou ALAC). |
| `protectedContent` | Fichier protégé | « nom » est protégé contre la copie (DRM). Les fichiers protégés ne sont pas pris en charge. |
| `tooLong(d)` | Son trop long | « nom » dure 25 min 12 s. La durée maximale est de 10 minutes par son. |
| `tooShort` | Son trop court | « nom » dure moins de 50 millisecondes, la durée minimale acceptée. |
| `corrupted` | Fichier illisible | « nom » est vide ou endommagé. Aucun son n'a été ajouté à la bibliothèque. |
| `writeFailed` | Échec de l'import | « nom » n'a pas pu être copié dans ScratchApp. Réessayez. |
| `notFound` au chargement | Son introuvable | La copie de « nom » a été supprimée ou modifiée en dehors de ScratchApp. Ce son a été retiré de la bibliothèque ; importez-le de nouveau. |
| Remplacement | Remplacer le son de la platine A ? | La platine A est en cours d'utilisation. « ancien » sera remplacé par « nouveau » et la platine s'arrêtera. « ancien » reste dans la bibliothèque. — **Remplacer** (Retour) · Annuler (Échap) |
| Bandeau, lancement | — | « boucle.wav » a été retiré de la bibliothèque : sa copie a été supprimée ou modifiée en dehors de ScratchApp. (plusieurs : « 3 sons ont été retirés de la bibliothèque : … ») |
| Bandeau, index illisible (CA 10) | — | La bibliothèque était illisible : elle a été réinitialisée. Importez de nouveau vos sons. |
| Bandeau, index partiellement illisible (CA 10) | — | Une partie de la bibliothèque était illisible : les sons concernés en ont été retirés. Importez-les de nouveau si besoin. |

« Fichier inaccessible » (UX §8.3) n'a pas de cas dédié dans `LibraryError` : en V1, une source illisible passe par `writeFailed` (« Échec de l'import ») ; un cas dédié demanderait un changement de contrat. **Décision PO D-58 (#73) : reporté en V1.1** ; en V1, « Échec de l'import » est une limite connue, de même que le dépôt sans effet d'un fichier que le système ne fournit pas.

### Pièges connus

- **Effacement du titre** : 4.1 corrige `DeckViewModel.apply` pour ne pas vider `loadedEntry` avant l'application de `.load` ; poser `loadedClip` en même temps que `loadedEntry`.
- **Fil principal** : aucun décodage, hachage ni copie sur le `MainActor` ; `Task.detached(priority: .userInitiated)` pour le décodage, résultat ramené par `await MainActor.run`. Les appels à la bibliothèque passent par l'acteur (`await`).
- **Deux imports en parallèle** (un par platine) : un état d'activité par platine ; le bouton « Importer » de la platine concernée est désactivé.
- **Annulation du décodage** : `CancellationError` ignorée silencieusement (nouvel import sur la même platine).
- **Démo** : `url(for: demoID)` lève `notFound` ; ne pas passer par l'URL.
- **Sans hôte** (tests, aperçus) : `tick()` appelle `pump()` (déjà en place) ; les commandes `load` s'appliquent donc à l'image suivante.
- **Relais d'affichage (#57, D-52)** : ne pas brancher `DisplayWakingEngine` sur un moteur rendu par un hôte avant le correctif #57 ; sans relais, la boucle d'affichage tourne en continu, ce qui reste correct.
- **Langue (D-42)** : identifiants en anglais, `///` en français, `//` en anglais.

### Completion Notes List

- **`AppModel`** :
  - implémente `DeckIntents` ;
  - **import** : `importAndLoad(_:on:)` ouvre l'accès à portée de sécurité seulement pendant `library.importFile(at:)`, met la liste à jour, puis applique les règles de remplacement ;
  - **chargement** : `library.url(for:)`, puis décodage dans `Task.detached(priority: .userInitiated)`, puis `send(.load)`, `loadedClip` et `loadedEntry` ;
  - **activité** : `.importing` puis `.loading` sur la seule platine concernée ;
  - **démo** : générée une seule fois, en tâche détachée, et partagée par A et B (RM-57).
- **Remplacement** (CA 7, D-40) :
  - l'état est lu dans l'instantané à la fin de la copie ;
  - platine chargée et active → confirmation ;
  - platine à l'arrêt ou vide (même plateau en rotation) → chargement direct ;
  - refus d'un nouvel import → bandeau « … a été ajouté à la bibliothèque. ». Pas de bandeau pour un refus de la démo ou d'un doublon, puisque rien n'a été ajouté.
- **Alertes et confirmations** : mises en file, la première est affichée. Les boutons les résolvent ; la fermeture par SwiftUI ne fait que relire les files, pour qu'une alerte suivante ne soit jamais annulée par erreur.
- **Bandeaux** (`ToastCenter`) : un seul à la fois, le plus récent remplace le précédent ; 4 s, ou 6 s au-delà de 80 caractères ; toucher pour fermer ; annoncé par VoiceOver ; fondu seul avec « Réduire les animations ».
- **Lancement** (`launch()`, une seule fois) : issue de la lecture de l'index, puis `reconcile()`, puis la liste. Le bandeau d'index illisible prime sur celui des entrées retirées (D-49).
- **API pour 3.5 et 5.2** : `load(_:on:)`, `loadDemoAndWait(on:)`, `unload(_:)`, `decks(carrying:)`, `alert` et `dismissAlert()`, `confirmation` et `resolveConfirmation(replace:)`, `toasts`, `libraryEntries`, `refreshLibrary()`.
- **`LibraryStore.indexRecovery`** (public, hors contrat, D-49) et `LibraryIndexRecovery` (`none`, `reset`, `partial`). `ScratchAppMain` la transmet par la fermeture `indexRecovery:` de l'`AppModel`.
- **Composition** (`ScratchAppMain`) : `ScratchEngine`, `AudioEngineHost`, `LibraryStore(locations: .standard())`, `AudioFileDecoder`, `UserDefaultsPreferencesStore`, puis `AppRootView(model:)`, qui affiche `RootView(model:intents:)`. `project.yml` déclare aussi les produits `ScratchLibrary` et `ScratchCore`, que l'app importe désormais.

  - **Hôte audio non démarré** (6.2, #57, D-52). Le moteur réel est pompé par `tick()` ; aucun `DisplayWakingEngine` n'est branché. `ScratchEngine.pump()` n'avance pas le temps : jusqu'à la 6.2, un START ne fait pas tourner le plateau à l'écran, alors que le faux moteur de l'aperçu l'animait.

  - **« Fichier inaccessible »** (UX §8.3) passe par `writeFailed` (« Échec de l'import ») : point ouvert pour Winston.
  - **Fenêtres** : `openLibrary`, `openSettings` et `revealLibraryInFinder` ne font rien (3.5, 3.4). Plusieurs fenêtres macOS partageraient le même modèle : à traiter avec la 6.2.
