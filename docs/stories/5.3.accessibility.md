## Story

**En tant qu'**utilisateur de VoiceOver ou du clavier,
**je veux** identifier et régler chaque commande,
**afin d'**utiliser l'app sans dépendre de la vue ni du seul toucher.

## Critères d'acceptation

1. **Libellés et valeurs (SF-83 ; 6.16 « Libellés VoiceOver »).** Chaque bouton, curseur et disque de l'écran principal annonce un libellé et sa valeur selon l'UX §11.2 ; un disque annonce sa platine, sa position et l'état de son moteur ; les annonces de l'UX §8.6 (son chargé, SET CUE, START sur platine vide, platine vidée) sont émises.
2. **Actions d'ajustement (SF-83 ; 6.16 « Régler le pitch par les actions d'accessibilité »).** Pitch (±0,1 %), résistance (±5 %), faders de voie (±5 %), crossfader (±5 %, actions « Butée gauche », « Centre », « Butée droite », butées physiques D-09), courbe (±10 %) et aperçu (±5 % de la durée) s'ajustent par les actions d'accessibilité, avec annonce de la nouvelle valeur.
3. **Clavier Mac (3.5, D-07 ; 6.16 « Navigation au clavier sur Mac », « Flèches sur une commande qui a le focus (Mac) »).** Avec l'accès clavier complet, la tabulation parcourt platine A (Importer, Aperçu, START/STOP, 33⅓, 45, SET CUE, CUE, Pitch, Pitch à 0, Résistance), table (fader A, fader B, Courbe, Hamster, Crossfader), platine B, puis la barre d'outils ; une commande réglable qui a le focus reçoit toutes les flèches (le crossfader ne bouge pas) ; Échap retire le focus et rend les flèches au crossfader ; les lettres de performance restent actives ; le disque n'est pas dans la boucle de tabulation.
4. **Contraste (WCAG AA, SF-83).** Les libellés respectent 4,5:1 (3:1 pour le grand texte et les contours de commandes) pour les couleurs de l'UX §9.2, vérifié par un test sur les jetons de couleur ; le mode « Augmenter le contraste » applique les variantes de l'UX.
5. **Sans geste sur le disque (NFR8).** START/STOP, CUE, crossfader et faders restent utilisables sans geste sur le disque ; le disque garde l'interaction directe (4.3).
6. **Liste de contrôle.** Une liste de contrôle (Accessibility Inspector sur Mac, VoiceOver sur simulateur iOS) est jointe à la PR ; la recette VoiceOver réelle sur iPhone et iPad relève de l'appareil (D-23). Les écrans de Hugo (Bibliothèque 3.5, Réglages 3.4, zone de dépôt 5.2) sont audités ; leurs écarts sont signalés en issues ou corrigés en accord avec Hugo.

### Pièges connus

- **Valeurs pendant le jeu** : la valeur du disque est lue au focus, **sans** trait « mise à jour fréquente » (pas d'annonces continues) ; seuls VU-mètres et SAT l'ont.
- **Flèches** : un seul gestionnaire décide (moniteur de 5.1) : si une commande réglable a le focus, la flèche lui revient ; sinon au crossfader ; ne pas laisser SwiftUI et le moniteur agir tous les deux.
- **Contraste** : calcul de luminance relative WCAG 2.x (sRGB linéarisé) dans le test ; pas de dépendance externe.
- **Langue (D-42)** : identifiants en anglais, `///` en français, `//` en anglais.
